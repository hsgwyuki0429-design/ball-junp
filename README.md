# ball-junp — 草原キャノン

草原で大砲を撃ち、バウンドをつないで得点を稼ぐブラウザゲームです。HTML・CSS・JavaScriptだけで動作します。

**[ブラウザで遊ぶ](https://hsgwyuki0429-design.github.io/ball-junp/)**

GitHub Pagesは `main` の更新時に動作確認を実行し、`dist` フォルダを自動公開します。

## 遊び方

1. 盤面をドラッグして大砲の角度を決めます。
2. 指を離すとチャージが始まります。
3. タップで発射。金色のタイミングなら倍率2倍でスタートします。

赤い的で得点、×2の床で倍率アップ、スライムで高くバウンドします。浮き島の下面・側面にも当たり判定があります。粘着トラップでその一球が終了しますが、獲得点は残ります。累計点で大砲がレベルアップします。

キーボードは左右矢印で角度、Spaceでチャージ・発射、Enterで次の一球を操作できます。

## 起動

`dist/index.html` をブラウザで開くと遊べます。ローカルサーバーを使う場合は、Python 3で次を実行してください。

```sh
python -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000` を開いてください。ビルドや依存パッケージのインストールは不要です。フォントにはGoogle Fontsを使用し、オフライン時はシステムフォントに切り替わります。

## 動作確認

Node.js 18以降で実行できます。

```sh
node --check dist/game.js
node check.cjs
```

発射、パーフェクト判定、得点、次の一球、浮き島の下面反射、粘着トラップ、倍率床、スライム、レベルアップを確認します。

## 構成

- `dist/index.html`: ゲーム画面
- `dist/style.css`: レイアウトとスタイル
- `dist/game.js`: 描画、操作、物理演算、得点処理
- `check.cjs`: ゲームロジックの動作確認
